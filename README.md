# FastFood Management System (DSS)

## Grade: 17/20 
---


## Project Overview
This system was developed as part of the **Software Systems Development (DSS)** course. It provides a comprehensive solution for managing a fast-food establishment, balancing the needs of staff management with customer order processing.

---

## 🎯 Learning Outcomes
* **End-to-End Development:** Implementation of the full software lifecycle, from requirements analysis to a functional prototype.
* **Design Excellence:** Heavy focus on software patterns to ensure code maintainability and scalability.
* **UML Proficiency:** Extensive use of modeling to map out complex business logic and data flows.

---

## 🚀 Key Features
* **Order Management:** Complete flow for placing, tracking, and completing customer orders.
* **Inventory & Menu Control:** Tools for managers to update products, prices, and stock levels.
* **Staff Coordination:** Modules for employee management and role-based access control.
* **Reliable Operations:** Built-in validation to prevent order errors and ensure data consistency.

---

## 🏗️ Architecture & Implementation
* **Language:** Java.
* **Patterns:** **DAO Pattern** for decoupled data persistence and the **Facade Pattern** for business logic organization.
* **Diagrams Included:**
    * **Domain Model:** Mapping the fast-food business entities.
    * **Class Diagrams:** Structural overview of the system[cite: 1].
    * **Sequence Diagrams:** Detailed logic for Authentication, Order Processing, and Inventory updates.
    * **Package & Component Diagrams:** Logical and physical system organization.

---

## 🛠️ How to Run
1. **Clone** the repository: `git clone https://github.com/gfsilva10/DSS-Project`.
2. **Setup:** Ensure you have the Java Development Kit (JDK) installed.
3. **Compile:** Build the source files located in the `src` directory.
4. **Launch:** Run the main application class to access the menu.
