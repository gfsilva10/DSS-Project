# FastFood Management System (DSS)

## Grade: 17/20 
---


## Project Overview
This system was developed as part of the **Software Systems Development (DSS)** course[cite: 1]. It provides a comprehensive solution for managing a fast-food establishment, balancing the needs of staff management with customer order processing[cite: 1].

---

## 🎯 Learning Outcomes
* **End-to-End Development:** Implementation of the full software lifecycle, from requirements analysis to a functional prototype[cite: 1].
* **Design Excellence:** Heavy focus on software patterns to ensure code maintainability and scalability[cite: 1].
* **UML Proficiency:** Extensive use of modeling to map out complex business logic and data flows[cite: 1].

---

## 🚀 Key Features
* **Order Management:** Complete flow for placing, tracking, and completing customer orders[cite: 1].
* **Inventory & Menu Control:** Tools for managers to update products, prices, and stock levels[cite: 1].
* **Staff Coordination:** Modules for employee management and role-based access control[cite: 1].
* **Reliable Operations:** Built-in validation to prevent order errors and ensure data consistency[cite: 1].

---

## 🏗️ Architecture & Implementation
* **Language:** Java[cite: 1].
* **Patterns:** **DAO Pattern** for decoupled data persistence and the **Facade Pattern** for business logic organization[cite: 1].
* **Diagrams Included:**[cite: 1]
    * **Domain Model:** Mapping the fast-food business entities[cite: 1].
    * **Class Diagrams:** Structural overview of the system[cite: 1].
    * **Sequence Diagrams:** Detailed logic for Authentication, Order Processing, and Inventory updates[cite: 1].
    * **Package & Component Diagrams:** Logical and physical system organization[cite: 1].

## 🛠️ How to Run
1. **Clone** the repository: `git clone https://github.com/gfsilva10/DSS-Project`[cite: 1].
2. **Setup:** Ensure you have the Java Development Kit (JDK) installed[cite: 1].
3. **Compile:** Build the source files located in the `src` directory[cite: 1].
4. **Launch:** Run the main application class to access the menu[cite: 1].
